# Decompose CGA closure

Status: `partial_bounded_reconstruction`

The repository now records a bounded closed-scheme decomposition ledger in
`data/processed/cga_closed_scheme_decomposition.csv`.

## Current Result

The ledger defines the required accounting drivers for a post-2006 CGA closure decomposition:
contributor count, contribution payroll base, contribution-rate policy changes, pensioner and
survivor counts, average benefits, State and other transfers, and residual attribution.

No numerical driver effect is reported yet. The current processed evidence does not contain the
annual count, payroll, benefit, and transfer component series needed to compute the decomposition.

## Interpretation Boundary

Closure to new entrants has a mechanical direction: absent offsetting factors, contributor inflows
fall as the closed population exits employment and beneficiary obligations remain. That mechanical
expectation is not a quantified causal decomposition until annual source data are registered and
the stock-flow identity is reconciled.
