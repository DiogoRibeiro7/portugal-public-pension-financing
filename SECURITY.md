# Security Policy

This project is a research repository and does not process production credentials or user secrets.

## Reporting

Report suspected credential leaks, unsafe data exposure, or supply-chain concerns privately to the repository owner through GitHub.

Please include:

- the affected file, commit, or dependency;
- the risk you believe it creates;
- enough detail to reproduce or verify the issue.

## Data Handling

Do not commit private credentials, paid-source exports with redistribution restrictions, or unpublished personal data. If a restricted source is needed for reproducibility, commit only metadata, acquisition instructions, and a hash of the local file.
